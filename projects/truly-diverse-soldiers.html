Truly Diverse Soldiers

A Bannerlord mod that gives every soldier a lasting identity, so armies stop looking like clones.

Status
Released, v1.0.0
Game
Mount & Blade II: Bannerlord v1.4.8
Built with
C#, Harmony

The problem

In the base game, every recruit of a troop type shares the same build, and every face is reshuffled from battle to battle. Soldiers have no lasting identity, so a large army reads as a crowd of clones.

Why you cared enough to build it, in your own words.

Who it is for

Bannerlord players, many of whom run large mod lists. That shaped the requirements: it has to coexist with other mods, be safe to add or remove mid-campaign, and be easy to configure.

Key decisions and tradeoffs

Build soldiers correctly from the start

Chose
A configurable share of regular soldiers, 30% by default, spawn as women built that way from the start, with body, animations and voice. Their faces, hair and tattoos come from their own culture's women.
Over
Swapping a soldier's appearance after it spawns.
Because
It looks and sounds right, and each culture keeps its character.

Derive identity from a stable seed instead of saving it

Chose
Each soldier's gender, face and build come from a seed hashed from the party, the troop type and the soldier's slot, so the same slot always produces the same soldier.
Because
The mod stores nothing in the save, which makes it safe to add or remove mid-campaign.
Cost
The game only tracks how many of each troop a party has, not individuals. When soldiers die or are upgraded, later soldiers shift into new slots and their appearance changes.

Let the player choose consistency or performance

Chose
An ExactFaces setting. On, which is the default, keeps every soldier's face identical between battles. Off uses the game's face cache, which is slightly lighter in huge battles but only similar, not identical.
Because
Players with very large battles and long mod lists have different limits than players who want exact faces.

Leave heroes and other mods' choices alone

Chose
The player character, companions, lords and all other heroes are never changed, and troops whose gender or face another mod has already set are left as they are.
Because
Many mods depend on heroes, so touching them would break the load orders this audience runs.

Simple, forgiving configuration

Chose
Three settings in one config file (female share, body variety, ExactFaces) and a message at the main menu showing the active settings. If the file is missing or a value is unreadable, it falls back to defaults.

Results

Released as v1.0.0 on Nexus Mods. It works in field battles, sieges and hideouts, and it was tested alongside a load order of more than 100 mods, including Dynamic Troop Equipment, Culture Diversity Mod, Living Armies and RBM.

Known limitations, stated on the mod page: soldier appearance shifts when slots change, Custom Battle is random each time because it has no persistent parties, and height is not varied yet.

Download count and any player feedback or endorsements, once you have them.

What I would do next

  • Vary height as well as weight and build, since it is the main thing still uniform.
  • Reduce how often appearances shift when soldiers die or are upgraded.
  • Read the player feedback after release and prioritize fixes by what people actually report.
